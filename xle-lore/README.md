# XLE canon files

These files are **placeholders**, not approved Xorishi lore. Replace each
PLACEHOLDER file with the corresponding hard-locked character personality and
canon context supplied by the project owner. Do not let models write to them.

The server refuses to provision or preview a character whose file is missing
or still starts with `PLACEHOLDER:`.

Each file should contain established identity, voice, relationships, boundaries,
and canon. Do not include API keys, server addresses, member personal data,
passwords, or private moderation information.
